# Plantillas

Obsidian las inserta desde la paleta de comandos, con la carpeta `plantillas`
configurada en `.obsidian/templates.json`. Se copia la plantilla y se llenan los
campos; el frontmatter sigue la [guía de la bóveda](../GUIA-OBSIDIAN.md).

| Plantilla | Para qué |
|---|---|
| [ADR](plantilla-adr.md) | Una decisión de arquitectura nueva, en `02-arquitectura/adr/` |
| [Requerimiento](plantilla-requerimiento.md) | Los requerimientos funcionales de un módulo |
| [Informe de sesión](plantilla-informe-sesion.md) | El informe que deja cada sesión con cambios, en `06-operacion/sesiones/` |
