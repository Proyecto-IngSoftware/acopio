# Diseños de Stitch

Las pantallas se diseñan en Google Stitch ([ADR-0011](../../02-arquitectura/adr/ADR-0011-interfaz-con-stitch.md))
y la estética la fija ese diseño ([ADR-0013](../../02-arquitectura/adr/ADR-0013-estetica-desde-stitch.md)).
Cada carpeta guarda la captura y el HTML de Stitch, la maqueta que Joseph aprobó y una
nota con las diferencias. No se escribe código de una pantalla sin su maqueta aprobada.

Las piezas que se repiten están en [_compartidos](_compartidos/README.md).
