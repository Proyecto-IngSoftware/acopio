# Contexto — índice

El suelo del proyecto. Se toca rara vez; cuando se toca, algo importante cambió.

| Nota | Qué responde |
|---|---|
| [problema.md](problema.md) | Qué está mal hoy y cuál es la causa raíz |
| [actores.md](actores.md) | Quién usa el sistema, en qué condiciones, con qué permisos |
| [glosario.md](glosario.md) | Qué significa exactamente cada término del proyecto |
| [fuera-de-alcance.md](fuera-de-alcance.md) | Qué se descartó **y por qué** |
| [investigaciones.md](investigaciones.md) | Qué se investigó para sustentar una decisión de diseño, con fuente |

## Cómo se usa

Antes de discutir un requerimiento nuevo, revisa
[fuera-de-alcance.md](fuera-de-alcance.md): puede que ya se haya decidido. Solo un
argumento nuevo justifica reabrir una decisión cerrada.

Antes de nombrar algo en código o en documentación, revisa
[glosario.md](glosario.md). El proyecto usa un solo vocabulario, en español.
